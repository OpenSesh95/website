How this works

This site is plain static HTML and CSS — no build step, no framework, no JavaScript. It is served as a Cloudflare Worker; pushing to the GitHub repo deploys it.

The design is called Aubergine Terminal: a window on an aubergine dot-grid, with the content kept as a set of short notes — an index on the left, the open note on the right. The notes layout takes its structure from alanagoyal.com; the theme, the words, and the stack are this site's own.

There is no tracking here: no analytics, no cookies, nothing phones home. The footer has said so from the first version, and it stays true.

The code-and-receipts record of the work itself lives on GitHub. This site stays at the level of a footprint — what things are, and where they live.
