How this works

You're reading a set of short notes. The index sits on the left and the open note on the right. Each note says one thing, so you can read one and leave, or follow a thread as far as it goes.

Pages open fast because there's little to send: plain HTML and one stylesheet, served from Cloudflare. Nothing waits on a script. Nothing breaks when a framework moves on. A note written today should read the same years from now.

Nothing watches you here. No analytics, no pixels, no tracking of any kind. What you read is your business.

The design is called Aubergine Terminal. It's quiet on purpose, so the words do the work.

If you want to see how it's made, the code and its history live on GitHub.
